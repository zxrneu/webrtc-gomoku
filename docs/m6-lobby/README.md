# 服务大厅文档（M6）

服务大厅位于独立 `/lobby` 页面，提供在线棋友、邀请组房、快速匹配与公开房间。Node 与 Rust 均支持首版协议；本轮断线广播修复仅适用于 Rust。

| 文档 | 用途 |
| --- | --- |
| [产品需求](prd.md) | 功能范围、传输边界、容量目标与验收要求 |
| [UI 与交互规划](ui-ux-plan.md) | 独立页面、列表与主要操作的布局 |
| [实施记录](implementation.md) | 已实现内容、验证历史与当前边界 |
| [容量与断线复审](capacity-review.md) | `5cc125c` 与 `2f6655e` 的本地对比、测量限制和复现命令 |
| [后续待办](tasks.md) | 已知缺陷、带宽优化及其验收条件 |

启动方式见[项目 README](../../README.md#服务大厅初版)与 [Rust 服务说明](../../apps/signaling-rust/README.md)。

截至 2026-10-20，Rust 修复版本为 `2f6655e`，本地构建与回归已通过，尚未部署。每节点 2000 个大厅会话与 1000 个房间的准入边界、100Mbps 公网出口下的本地测量，均不等于生产稳定容量承诺。后续部署与缺陷状态更新至待办；测量报告保留当时环境和结果。
