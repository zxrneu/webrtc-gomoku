# 服务大厅初版实施记录

日期：2026-10-19。

## 已实现

- 独立 `/lobby` 页面，不展示棋盘；暖纸色、黑白棋子装饰与琥珀色操作按钮。桌面左右布局，760px 以下改为单列，320px 起可用。
- 在线棋友 / 房间广场使用等宽分段切换，桌面 18px、手机 16px 字号，点击区域高 48px 起；快速匹配与自己开一桌采用等宽等高卡片，分别说明匹配和公开建房的用途。
- 自动临时昵称、重名区分、修改昵称、在线会话与等待桌数、按昵称搜索、只看可邀请用户、分页加载。
- 定向邀请：接受后自动创建私密双人房；拒绝、取消、30 秒过期、离线撤销、重复接受与交叉邀请幂等处理。
- 快速匹配：队列撮合、取消、60 秒超时；迟到的配对结果不能强行拉回已取消的用户。
- 公开建房、房间广场、加入房间、房主切换公开状态、退出房间返回大厅。
- 入座后自动回到原棋盘页，复用连接编排、落子、聊天、悔棋、换边与富媒体能力。
- 同一信令连接复用大厅和房间消息；空闲断线与半开连接重试；当前窗口保存座位凭证和校验后的棋谱，刷新时先经服务端校验再恢复；失效座位返回大厅提示结束。
- `/config` 能力发现、旧服务端降级、Unicode 昵称和嵌套协议校验；列表只公开临时用户标识，不公开座位凭证。
- Node WebSocket 单帧上限 64KB、每 IP 最多 10 个连接、每浏览器最多 2 个会话、最多 2000 个大厅会话及 1000 个房间，邀请与建房限频。
- Rust 服务端支持同一大厅协议和能力声明，复用原有 RoomTable / SeatRegistry / Redis 房间准入与恢复；包含邀请、匹配、公开房间、过期撤销、刷新身份转移与请求限流。昵称与 TS 统一使用 Unicode 字母 / 数字类别，避免组合标记等非法昵称使前端拒绝列表。

## 运行

```sh
pnpm build
pnpm start
```

访问 `http://localhost:3000/lobby`。开发时分别运行 `pnpm dev:server` 与 `pnpm dev`；Vite 已代理 `/config` 和 `/signal`。

在线产物：`packages/web/dist/index.html`。独立单文件：`dist/gomoku-standalone.html`，由单独的 `standalone` 构建生成，大厅代码与样式在构建时剔除。

## 复审修复（2026-10-20）

- 窗口会话保存并恢复执色，避免换边后刷新将房主强制恢复为黑方。
- 棋友列表直接显示服务端当前页，移除不会失效的前页合并缓存；人数减少时自动回退到有效页。
- `lobby-ready` 与列表查询可在业务请求等待期间发送，避免在线状态永久滞后。
- Node 同一窗口刷新先替换旧会话，再检查浏览器配额，迟到的旧连接关闭不影响新会话。
- Rust 已被接管的物理连接永久撤权，清空房间后不能再次 create/join 夺回座位。
- Rust 每周期构建并缓存一份公共投影，避免为每位用户重复计算和排序名册。相同 release 内存基准下，2000 人 flush 从 3681ms 降为 33ms；不包含网络及真实 Redis，不代表线上吞吐。
- Rust `cargo test` 共 249 项通过，build、fmt 与 Clippy 全绿。

## 当前边界

截至 `2f6655e`，Rust 的断线和旧协议房间操作不再立即全员广播；公共状态变更合并到每秒发布周期，无变化不广播，列表查询单独响应。邀请、匹配、房内离线通知仍定向即时发送，座位过期使公共投影失效。新增 5 项先失败后通过的回归，Rust 254 项、TS 1031 项测试及完整 E2E 通过。具体数据与限制以[容量复审](capacity-review.md)为准。

HTTP 分页、增量通知和后台页面暂停刷新尚未实现；Node 未同步 Rust 合并发布机制。缺陷状态及后续验收集中维护于[大厅待办](tasks.md)。本地修复提交不代表已部署到线上，部署前需核对实际运行版本。

## 四项缺陷修复（2026-10-20）

- Node 使用独立物理连接权限记录，接管座位时永久撤权旧连接；允许旧连接响应心跳，但阻止其 leave、信令与再次开房/加入，座位释放后也不恢复权限。
- Node 大厅已登记会话增加每秒 30 次请求限流，固定时钟控制窗口，拒绝时不改变业务状态。
- 前端进入失败时停止列表查询，保留配额原因；用户重试成功后恢复查询。
- 新弹窗在读取会话前清除复制的窗口身份和座位凭证；真正刷新、历史返回保留本窗口会话，不清除浏览器共享标识。
- 新增 11 项先失败后通过的 TS 用例，70 文件、1042 项通过。扩展协议和窗口边界脚本加入默认 E2E，覆盖弹窗刷新、复制对局凭证与旧连接永久撤权。

大厅首期接入 **Node `apps/server` 与 Rust `apps/signaling-rust`**。在线名册、邀请和匹配队列均为节点内存状态；Rust 原有 Redis 跨节点房间信令、准入与座位恢复继续复用，尚未实现跨节点统一名册或撮合队列。服务重启不保留大厅状态；本地 2000 会话与 1000 房间压测、断线广播修复和已知问题见 [容量复审](capacity-review.md)。PRD 的线上转化率、P95 延迟和压力目标仍需部署后测量，不能由本地测试推定。

当前窗口的座位凭证保存在 sessionStorage，不写 URL、列表或日志；浏览器阻止存储时仍可对局，但不承诺刷新恢复。大厅列表为实时会话，不代表注册账号人数。
