# v1.4.0 · 大厅、富媒体聊天与 HTTPS

相比 v1.3.0，本版新增服务大厅、富媒体聊天、更强的本地 AI，并完善断线恢复与 HTTPS 部署。

## 新增与改进

- 服务大厅：在线名册、昵称搜索、定向邀请、快速匹配、公开房间与刷新恢复；Node/Rust 均可使用。
- 聊天：独立聊天页签、未读提示、图片、文件和最长 60 秒语音消息；支持分片校验、进度与取消。
- 本地 AI：证明数搜索、威胁分析、独立 Rust/WASM 内核和落子提示。
- 联机：执色选择、协商换边、手数显示，完善座位所有权、断线重连、棋谱对账和换房隔离。
- HTTPS：Node/Rust 原生 HTTPS/WSS、局域网证书配置与部署恢复说明。

## 发布前修复

- 拒绝含空字节的 HTTP 路径，修复单个恶意请求可使 Node 服务崩溃的问题。
- Docker 构建补齐 tooling 目录，修复 Vite 配置依赖缺失。

## 下载与运行

- gomoku-standalone.html：离线单文件，通过文本连接码或扫码建立 P2P。
- gomoku-signaling-linux-amd64-gnu.tar.gz：Linux x86_64 服务包，包含网页及配置；需要 glibc 2.36 或更新版本（例如 Debian 12）。
- gomoku-signaling-darwin-arm64.tar.gz：Apple Silicon macOS 服务包，包含网页及配置。
- SHA256SUMS：下载文件校验值。

解压服务包后，在解压目录运行：

```sh
GOMOKU_REDIS_ENABLED=false ./gomoku-signaling
```

打开 http://localhost:3000/lobby。需要录音时配置可信 HTTPS，详见包内 README 与仓库 docs/https.md。

## 验证与边界

构建、1232 项单元测试、277 项 Rust 测试、Node 真实 P2P 全套 E2E、Rust 对局/大厅/原生 HTTPS 以及二维码回归均已验证；Docker linux/amd64 镜像已构建并通过启动检查。发布源码快照已独立构建并通过全部单测；测试流程见 [测试说明](../testing.md)。

本机 VPN 环境下，无媒体权限的单文件 P2P 检查出现 ICE 超时；使用测试媒体权限后连通。按维护者决定，本版跳过 VPN 环境验收，此项不计为通过。公网跨网络/TURN、手机真实麦克风和 Redis 多节点部署未在本轮重新验收。
